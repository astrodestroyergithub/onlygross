## Deploying to Netlify

1. Drag and drop this unpacked `onlygross` folder (or upload the repository) directly into **[Netlify Drop](https://app.netlify.com/drop)** or connect via Git.
2. `netlify.toml` and `_redirects` are pre-configured for zero-config static hosting and instant SPA routing.
3. Custom SVG favicon (`favicon.svg`), responsive multi-device stylesheet (`styles.css`), optimized visual assets (`assets/`), and full interactive logic (`app.js`) are bundled right out of the box.
